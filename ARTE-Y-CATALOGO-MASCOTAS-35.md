# Arte y catálogo de mascotas 35

Se generaron 19 ilustraciones originales con **imagegen integrado**, modo **generate** a partir de referencias (no edición de los JPG). Fondo transparente conservado sin retoques de píxeles. Las cuatro ilustraciones anteriores no se sustituyeron.

La referencia de estilo para cada ilustración fue `assets/pets/cat-v1.png`. La referencia de tema se indica abajo. Las dos referencias de kitsune se reunieron en Inari; el hámster y gato calicó del collage se reunieron con sus referencias individuales. El collage dio además seis compañeros distintos. El resultado tiene 19 nuevas mascotas.

## Prompt exacto

Cada llamada utilizó este prefijo, seguido del texto «Subject» de la tabla y finalmente el sufijo. Se adjuntaron primero la referencia de estilo y luego la de tema. `transparent_background: true`.

**Prefijo**

Use case: stylized-concept. Asset type: one transparent game companion pet PNG. Generate an original illustration, not an edit. Input image 1 is STYLE reference ONLY: match its polished chibi anime rendering, delicate dark warm outlines, soft pastel cel shading, glossy eyes, warm blush and cozy romantic proportions. Input image 2 is SUBJECT reference ONLY, reinterpret it in image 1's style; do not copy signatures or text. Subject: 

**Sufijo**

 Composition: exactly ONE animal, full body seated or naturally posed, three-quarter front facing viewer, centered in a square with generous 12% transparent padding. Pet occupies about 75% of canvas. Clean readable silhouette at 85 pixels, all ears/tails/accessories inside frame. Genuine transparent alpha background. No floor, cast shadow, scenery, floating decorations, typography, signature, watermark, panels or extra animals.
